# Visual Portfolio Hub

The repository root contains a static dark-mode portfolio hub inspired by systems dashboards rather than a conventional developer landing page. It uses the public GitHub REST API at runtime to show actual public repository and follower counts and reads the published public repository index dynamically.

## Publishing it

Open **Repository Settings → Pages**, select **Deploy from a branch**, then choose the **main** branch and the **/(root)** folder. GitHub Pages will publish the hub at:

`https://wasayb.github.io/wasayb/`

The hub intentionally keeps the 50-project build program distinct from public GitHub metrics because those product repositories are private during validation. It also makes no claim of commercial deployment, customer use, or compliance certification.
